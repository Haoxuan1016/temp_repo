Many registers: the operands come from registers, so the instruction does not have to wait for memory and can finish in one cycle.

Pipelining

  • The instruction is split into stages. Name two of: fetch, decode, execute, write-back.
  • Several instructions occupy different stages at the same time.
  • Each stage takes one clock cycle.
  • Once every stage is busy, one instruction finishes on each clock cycle. Throughput rises. A single instruction does not get shorter.

When an interrupt arrives

  • It is checked at the end of the current instruction. On RISC that is one cycle, so it is taken quickly. On CISC the instruction may still have many cycles left, so the interrupt waits.
  • Later instructions are already in the pipeline. Flush those stages, or save the contents of each stage. The instruction in write-back can finish.
  • Save the program counter and the registers, run the interrupt service routine, restore them, then fill the pipeline again.
  • Frequent interrupts keep emptying the pipeline, so the throughput gain is lost.

The mark is for what the processors do. In a comparison, name both architectures: SIMD and MISD are both parallel and both use more than one processor; SIMD applies one instruction to many data items, while MISD applies different instructions to one data item. Expanding the initials on their own scores nothing.

Massively parallel. A very large number of processors are linked and act as one machine (“many” or “thousands”; “several” does not score). They work at the same time on one problem, each on its own part. They exchange data through an interconnection network, or through shared memory.

Full adder — A, B and a carry in

Sum = A ⊕ B ⊕ Cin

Cout = A.B + Cin.(A ⊕ B)

The same Cout is A.B + A.Cin + B.Cin. It is 1 when at least two of the three inputs are 1. Sum is 1 when an odd number of inputs are 1.

Two half adders, then OR the two carry outputs. Cout of one full adder is Cin of the next bit.

Karnaugh maps and a sum of products

Truth table to sum of products

  • One product for every row in which the output is 1.
  • Every input appears in every product. Complement an input that is 0 in that row.
  • Join the products with +. Leave it unsimplified until a later part asks.
  • The mark is usually one for every two correct products.

Reading the loops

  • Headings run 00, 01, 11, 10 on both edges. One bit changes between neighbours, and the map wraps: the first cell is next to the last.
  • For three variables the single variable labels one side and the pair labels the other, still in that order. Use the labels printed on the paper.
  • Fill every cell. On a two-mark map, one wrong cell loses one mark and two wrong cells lose both.
  • Stop if the question says not to simplify further. The next part is the factorised form, for example A.C + B.C = C.(A + B), and that step is marked on its own.
